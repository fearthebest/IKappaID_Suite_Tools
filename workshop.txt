title=IKappaID Suite Tools
description=Build 42 admin suite — [b]v0.3.2.0 BETA[/b]. Claims, recovery journal, server utilities, and optional World Edit / Vehicles / Economy / Loot addons.
description=
description=[b]Requires[/b] IKappaID UI Framework (Mod ID: IKappaID_UI). Subscribe and enable it with this suite.
description=
description=[b]BETA[/b] means the suite is ready for real multiplayer playtesting on private servers. Core tools are usable; please share feedback in Discussions if something breaks — steps and console.txt help a lot.
description=
description=English only in this release.
description=
description=A clear control panel for multiplayer servers and the people who play on them — land and vehicle claims, recovery journal, and optional world tools. Dark layout with orange IKappaID accents; pairs with IKappaID Phone Shop for economy cash.
description=
description=[b]For players[/b]
description=- Claim a safehouse or a vehicle so it is yours — who may enter, drive, loot, or use storage is set by permissions you control
description=- Add friends or members when you want company; keep strangers out when you do not
description=- Recovery journal: save your character on an item and restore skills and progress after death (if the server allows it)
description=- See who owns what at a glance; fewer arguments over whose base or car it is
description=
description=[b]For hosts and admins[/b]
description=- Open the panel anywhere with [b]Ctrl+Shift+W[/b]
description=- Player care, weather and time, moderation helpers, and common server chores in one place
description=- Decide what players can do themselves vs staff-only in sandbox options
description=- Made for real multiplayer: the server stays in charge; clients see what the server allows
description=
description=[b]Optional addons[/b] — turn on only what your server needs
description=- [b]World Edit[/b] — paint or remove tiles, inspect builds, protect areas, password locks on containers
description=- [b]Vehicles[/b] — find, move, repair, or remove vehicles for staff. Requires World Edit (Mod ID: IKappaIDSuiteToolsTiles)
description=- [b]Economy[/b] — bank accounts, transfers, and player-run shops (works with IKappaID Phone Shop)
description=- [b]Loot[/b] — refill container loot in an area or building for events, resets, or dead towns
description=- [b]Admin[/b] — spectator (Ghost), kick, and ban using vanilla server commands
description=
description=[b]Known limits (BETA)[/b]
description=- Destroy, pickup, and grief-build on claimed/protected tiles, and loot from guarded containers, are reversed on the dedicated server. A modified client cannot keep those changes.
description=- Jobs panels use the suite chrome; the hub dashboard uses IKappaID UI. Both are intentional.
